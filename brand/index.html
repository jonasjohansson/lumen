01 Logo family

One hand, drawn in light

Every mark is the same fluid script, set in a halftone of sharp dots. Softness only ever comes from the dots getting smaller. Each SVG has every dot as a vector circle, so it scales to any size; the PNGs are 4096 px wide. Each file is cropped to its ink on a transparent ground: light is Lumen white for dark grounds, dark is black for light ones.

02 Symbol

lp, the one-stroke monogram

The L's foot runs under the p and into its bowl. From 64 px down, use the small cut: fewer, bigger dots that still read as a screen. Below about 48 px the dots stop holding.

04 Type

DIN 2014

The script is for the marks only. Everything set in type is DIN 2014 (ParaType, via Adobe Fonts): uppercase with open tracking for labels, DIN 2014 Narrow Bold for big headlines, sentence case for running text.

05 Use

Keeping it right

  1. Use the files

    Never retype the name in a script font or redraw the dots. Export from the logo lab or take a file from below.

  2. Leave room

    Keep clear space of at least half the symbol's height on every side of any mark.

  3. Mind the size

    Word marks from 240 px wide on screen (40 mm in print). The symbol from 64 px, the small cut down to 48 px.

  4. Two colours only

    Lumen on Night, or Night on Lumen and white. No gradients, tints or outlines on the mark.

  5. Don't stretch or blur

    Scale in proportion. The dots stay sharp; never add a glow or a drop shadow.

  6. Over photos

    Place light marks on the darkest, calmest part of the image, or use the symbol in a corner.

06 In use

On Lumen's own images

Minimal layouts on photos from the lumenproject.se gallery (several by Olga Androsova). The mark sits in the darkest, calmest part of the picture; where the picture has none, a soft shade is added under it, never a box.
